02 / Make yourself at home

A few things
before you record.

The standalone download is being prepared. These steps describe the current app, still named Recordly inside macOS.

Read the project guide ↗

  1. Download and install

    When a release is available, download its standalone archive from GitHub Releases, extract it and move the app to Applications. Check that release’s installation and signing notes before opening it.

  2. Allow audio capture

    Allow Microphone access when prompted. Use the app’s Grant Access action for Screen Recording, then enable the app in System Settings → Privacy & Security. macOS requires this permission for system audio. Restart the app if prompted.

  3. Prepare your models

    Open Models. Download Parakeet Ultra, or download and select Parakeet TDT 0.6B v3. Downloading and selecting are separate actions. Install the Speaker Separation package for remote speaker labels.

  4. Make a short test recording

    Check both audio sources, play the recording back and try transcription. An internet connection is needed for model downloads. Once installed, speech processing runs locally.

03 / The small print

A Mac.
A little preparation.

macOS 15 or later

Native speech processing has been verified on Apple Silicon, specifically an M3 Pro. Intel speech processing is not confirmed. Windows, Linux, iPhone and iPad are not supported by this app.

Room for your recordings and models

Models are downloaded separately and need local storage. No minimum memory or free-space figure has been validated for a public release yet.

Useful, with room to improve

Transcription and speaker labels need review, especially with overlapping voices or short contributions. Summary generation is currently disabled. Ask everyone’s permission before recording.

04 / A few answers

Good to know.

Is Barkenson free?

Yes. This is a free project made for its author and friends. The source is available on GitHub.

Can I download it now?

A public standalone release is still in preparation. Historical build records in the repository are not downloadable app releases. This page will link to an actual release file once one is published and verified.

Does my audio leave my Mac?

Recording and speech processing run locally. Initial model downloads need internet access. This website uses no analytics, external fonts or third-party scripts.

Will it identify every speaker correctly?

No. Speaker separation can confuse voices or leave labels incomplete. Without the speaker model, transcription can still run with reduced speaker labelling. Review the result against the audio.

What can I export?

You can export the transcript and explicitly create combined audio for sharing or keeping elsewhere. Review exported files before sharing a private conversation.

Why does macOS call it Recordly?

Barkenson is the working name for this site. The current app and its local storage folders still use Recordly. Final branding and release screenshots are being prepared.

What if macOS will not open the app?

Follow the signing and installation notes attached to the eventual release. The current local development certificate is not a notarised Developer ID release. Do not disable macOS security protections to install an unverified copy.
