Barkenson 0.1.0 · Preview

Installation guide.

macOS 15 or later · Apple Silicon for transcription and speaker separation.

1. Download and install

Download Barkenson for Mac, extract the ZIP and move Barkenson.app to Applications. Xcode is not needed.

If you already use Barkenson or its previous name, Recordly, stop recording and quit the old app first. Keep a backup of the old application and its data before replacing it. Keep one active installed copy; your existing recordings, models and settings retain their original locations.

2. Open the preview

This preview uses a local development signing certificate. It is not notarised and is not a Developer ID release. macOS may question or prevent first launch. Read the release notes before opening it; do not disable macOS security protections or install a signing private key.

Check the archive in Terminal if needed:

shasum -a 256 Barkenson-0.1.0-build5-macOS.zip

The expected SHA-256 is:

1ee36de64e35f7750bfd621ae338347b75d6cb2582f60e03e04e76eaf71c5124

3. Allow audio access

Allow Microphone access when prompted. Use Open Settings in the app to enable Screen & System Audio Recording in System Settings → Privacy & Security. This permission is used for system audio; screen video is not saved. Follow any restart instruction macOS displays.

4. Prepare your models

Open Models. Download a transcription model, then select it. Download and selection are separate actions. The speaker separation package is optional; without it, transcription can continue with reduced speaker labelling.

Model downloads need an internet connection and local disk space. Recording and transcription run locally once setup is complete.

5. Make a short test recording

Record your microphone and call audio, play it back, then run transcription. Review the speaker labels, try TXT transcript export or combined audio export, and reopen the app to check your recording.

If you need help, report a problem on GitHub. Remove private meeting content before attaching files or screenshots.
